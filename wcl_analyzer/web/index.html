Топ прогресса без лога — выбрать рейд и сложность

Бой гильдии, которая первой в мире убила босса на этой сложности: урон, сейвы и кто какие кулдауны жал, смерти, состав, заметка MRT. Без сравнения и без вашего лога; нужен только ключ Warcraft Logs. «Все боссы» — вкладка на каждого босса. На героической и обычной сложности рейтинга прогресса нет — берётся самый ранний по дате килл среди 300 лучших в рейтинге WCL. Не все эпохальные логи открыты: если лог гильдии закрыт, программа возьмёт следующее место (до 6-го) и напишет, чьи логи недоступны.

План сейвов по составу — состав из игры и длительность боя

Бой берётся у лучших гильдий: из рейтинга Warcraft Logs — киллы этого босса с длительностью ближе всего к указанным минутам. Их пики урона и самые тяжёлые моменты — то, на что нужны сейвы; что жмут лучшие гильдии — подсказка, какие кулдауны ставить. Кулдауны — из вашего состава: основные по классу и спеку, а таланты (Апофеоз, Перерождение, Древо Жизни…) — если их жмут лучшие гильдии: в экспорте талантов нет. Аддон: WoWUtils Group Export. Состав запоминается на этом устройстве.

Выбраны все боссы отчёта — по одному бою на босса (последний килл, без киллов — лучший пулл): на каждого босса — свой полный разбор боя, как у одного лога (главное по бою, кому что поправить, урон, сейвы, смерти, план и заметка MRT с сейвами и кулдаунами лекарей), затем ротация по боссам против топ-1, чтобы хватило лимита WCL.

Лучшие логи (эталоны)

Каждое сравнение запоминает свой эталон в этом браузере. Обновление скачивает свежий рейтинг лучших логов.

История разборов

Последние 40 разборов с Excel-файлами хранятся в этом браузере: их можно открыть без интернета и без повторной загрузки.

Куда сохранять файлы

Сюда сохраняются файлы, которые вы скачиваете кнопками: Excel разборов и «Мои данные → Сохранить в файл». Если папка не выбрана — в «Загрузки».

Сейчас: «Загрузки» (по умолчанию)

Скачанные с Warcraft Logs логи сюда не сохраняются: программа держит их в своей базе-кэше, чтобы повторный разбор не тратил лимит запросов. Это не файлы для чтения, а один файл базы:
Кэш чистится сам при каждом запуске программы: удаляется скачанное больше 3 недель назад, и он не растёт больше 500 МБ (сверх — удаляется самое старое). Данные хранятся сжатыми. Эталоны, история и настройки при очистке не пропадают — понадобятся логи, скачаются заново (это потратит лимит запросов WCL).

Мои данные

Ключ API, эталоны, настройки и история разборов хранятся только в этом браузере — на сервере их нет. Сохраните копию в файл, чтобы перенести всё на другое устройство или не потерять при очистке браузера.

Чтобы перенести данные с ПК, вставьте ссылку переноса в окне «Подключить ключ API».

Открыть на телефоне или другом устройстве

Ключ Warcraft Logs API

  1. Откройте warcraftlogs.com/api/clients и войдите.
  2. Нажмите Create Client: имя любое, Redirect URL — http://localhost.
  3. Скопируйте Client ID и Client Secret сюда.

Ключ бесплатный и у каждого свой. Он хранится только в этом браузере и отправляется с запросами к Warcraft Logs; сервер его не сохраняет. На другое устройство его можно перенести кнопкой «На другом устройстве».

Есть ссылка переноса с другого устройства?

На другом устройстве нажмите «На другом устройстве», скопируйте ссылку под QR-кодом (или отсканируйте код и скопируйте открывшийся адрес) и вставьте сюда.
