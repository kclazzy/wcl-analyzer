# WCL Analyzer — как пользоваться

Руководство для новых пользователей. Скачать программу: [для компьютера (Windows)](https://github.com/kclazzy/wcl-analyzer/releases/latest/download/WCL-Analyzer.exe) · [для телефона (Android)](https://github.com/kclazzy/wcl-analyzer/releases/latest/download/WCL-Analyzer.apk).

## Что умеет программа

**WCL Analyzer** — бесплатный помощник для гильдий без своего аналитика: вставляете ссылку на лог Warcraft Logs и получаете разбор, как у топовых гильдий.

1. **Ротация и бурсты** — каждый DPS рейда сравнивается с топ-1/топ-3 своего спека: что жать иначе и что тренировать первым.
2. **Урон по рейду и сейвы** — график урона, кто какие сейвы нажал и когда, сравнение с лучшими киллами и готовый план сейвов на следующий пулл. Если ваш бой длиннее, чем у топа, оставшиеся пики программа распишет сама. Сейвы и кулдауны лекарей — одной заметкой для MRT.
3. **Нанесение урона** — когда нажат героизм, кто прожал бурсты под него, окна на боссе, под которые жмут бурсты (снять щит, уязвимость), и кто попал в них бурстом; сравнение с тем, когда героизм и волны бурстов делают лучшие гильдии.
4. **Танки** — крупные удары босса по танку (танкбастеры): был ли танк прикрыт своим кулдауном или сейвом лекаря, кто умер от удара и какой кулдаун в этот момент был готов, как прикрывают эти удары лучшие гильдии, и заметка MRT для танков на следующий пулл.
5. **Топ прогресса** — бой первой гильдии, выложившей открытый лог убийства: в какие моменты и чем сейвились лучшие. Не нужно сравнивать со своим логом. Любая версия игры: Retail, Classic, Classic Anniversary, Season of Discovery, Classic Era.
6. **План по составу** — скопируйте состав из игры (WoWUtils Group Export), укажите примерную длительность боя, и программа подберёт киллы топа похожей длины и распишет сейвы для MRT.
7. **Кому что поправить** — смерти и ошибки по игрокам. У каждой механики есть ссылка на гайд и ролик с Mythic Trap и краткое описание, а если гайда нет — описание с Wowhead.

Все боссы вечера за один раз, история разборов, выгрузка в Excel, версии для компьютера и телефона. Ключ Warcraft Logs у каждого свой, данные хранятся только у вас.

## 1. Установка

Скачайте версию для своего устройства — ссылки всегда ведут на самую свежую версию. Дальше программа обновляется сама, скачивать заново не нужно.

| Устройство | Скачать | Как запустить |
| --- | --- | --- |
| Компьютер (Windows 10/11) | [WCL-Analyzer.exe](https://github.com/kclazzy/wcl-analyzer/releases/latest/download/WCL-Analyzer.exe) — 25 МБ | Двойной щелчок. Если Windows пишет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае» (у программы нет платной подписи). |
| Телефон (Android 7 и новее) | [WCL-Analyzer.apk](https://github.com/kclazzy/wcl-analyzer/releases/latest/download/WCL-Analyzer.apk) — 38 МБ | Откройте скачанный файл и разрешите установку из этого источника — обычный шаг для приложений не из Google Play. |

Classic, Classic Anniversary, Season of Discovery и Classic Era: ссылку на отчёт с их сайта (`classic.`, `fresh.`, `sod.`, `vanilla.warcraftlogs.com`) программа понимает сама, ключ тот же. Таблицы кулдаунов программы — по основной игре, поэтому на этих версиях оценки «был готов», «нажато реже» и план танков не считаются (об этом пишет плашка над разбором).

Все версии и список изменений — на странице [выпусков](https://github.com/kclazzy/wcl-analyzer/releases/latest). iPhone не поддерживается.

На компьютере откроется чёрное окно и страница программы в браузере. Чёрное окно не закрывайте, пока пользуетесь: в нём работает программа.

Попробовать без ключа можно сразу: под полем ссылки есть «разбор боя» и «разбор игрока» на демо-данных.

## 2. Ключ Warcraft Logs

Ключ нужен один раз и бесплатен; он хранится только на вашем устройстве.

1. Откройте [warcraftlogs.com/api/clients](https://www.warcraftlogs.com/api/clients) и войдите в свой аккаунт.
2. Нажмите **Create Client**: имя любое, Redirect URL — `http://localhost`.
3. В программе нажмите «Подключить ключ API» и вставьте **Client ID** и **Client Secret**. Программа проверит ключ и запомнит его.

На телефон ключ можно не вводить заново: на компьютере «На другом устройстве» → «Скопировать ссылку», на телефоне — окно ключа → «Есть ссылка переноса…». Эту ссылку и QR-код не показывайте другим — в них ваш ключ.

Видно, какой ключ подключён, в окне «Ключ API подключён» вверху — там показан Client ID; Client Secret программа не показывает, он всегда есть на warcraftlogs.com/api/clients. Вернуть ключ из резервной копии: «Мои данные» → «Загрузить из файла» (если при сохранении стояла галочка «Включить в файл ключ API»).

## 3. Разбор боя

Основной сценарий — ссылка на отчёт и одна кнопка «Разобрать бой».

1. Скопируйте ссылку на отчёт с warcraftlogs.com (вида `https://www.warcraftlogs.com/reports/…`; для Classic, Season of Discovery и других версий — с их сайта: `classic.`, `sod.`, `fresh.`, `vanilla.warcraftlogs.com`), вставьте в поле и нажмите **«Найти бой»**.
2. Выберите:
    - **Бой** — конкретный пулл или «Все боссы отчёта»;
    - **Ротация: игрок** — «Все игроки» (все DPS) или один игрок для подробного разбора;
    - **Ротацию сравнить с** — топ-3 (по умолчанию), топ-1 или «Без ротации», если нужны только урон, сейвы и смерти.
3. Нажмите **«Разобрать бой»**. Урон, сейвы и смерти появятся через несколько секунд, ротация досчитается следом — её вкладка заполнится сама.

Что смотреть в результате:

| Где | Что там |
| --- | --- |
| «Главное по бою» | главные проблемы пулла в несколько строк |
| «Кому что поправить» | замечания по игрокам; у механик — ссылка на гайд, «i» краткое описание и ▶ ролик |
| «Полученный урон и сейвы» | график урона по рейду, план сейвов, самые тяжёлые моменты, сравнение с лучшими киллами |
| «Нанесение урона» | героизм, усиления, окна на боссе для бурстов и бурсты DPS по времени боя; кто прожал главный бурст под героизм и в окно, сколько раз из возможных (пока был жив); как это делают лучшие гильдии |
| «Танки» | каждый танкбастер: чем танк был прикрыт, «без кулдауна» и что было откатано, смерти от удара; защитные кулдауны танков; доля прикрытых ударов у лучших киллов; план и кнопка «Скопировать для MRT (танки)» |
| «Игроки», «Механики», «Смерти», «Пуллы» | подробности по каждой теме |
| Вкладка ротации | чем игра DPS отличается от топа его спека и что тренировать первым |

Кнопка **«Скачать Excel»** сохраняет весь разбор одним файлом.

## 4. План сейвов и заметка MRT

План говорит, кто и когда жмёт рейдовый сейв или кулдаун лекаря на следующем пулле; всё это собрано в одну заметку для аддона Method Raid Tools.

1. Откройте вкладку «Полученный урон и сейвы».
2. Нажмите **«Скопировать для MRT»**. Кнопка стоит под планом сейвов или под «Самыми тяжёлыми моментами» — там, где заметка подробнее.
3. В игре: `/mrt` → «Заметки» → вставить (Ctrl+V) → «Отправить».

Как читать план:

- **Время** — от пулла, а со 2-й фазы — от начала фазы (`p2`, `p3`): если фаза придёт раньше или позже, таймеры сдвинутся вместе с ней. Номера фаз сверьте со своим босс-модом.
- **«Как у топа»** — тот же кулдаун на этот пик жмут лучшие гильдии.
- **«доп.»** — кулдаун свободен и иначе простоял бы весь бой: план ставит его на пик, где сейвов пока меньше всего (до 4 сейвов на пик), он тоже входит в заметку MRT.
- **«Запасные»** — что ещё откатано к этому моменту и не сломает остальной план.
- **«По топу»** — пик, до которого ваш бой не дошёл; он в таблице для сведения, в заметку MRT не входит.
- Тег **«лекарь»** — кулдаун лекаря на себя (Апофеоз, Древо Жизни, Перерождение…) на самые тяжёлые пики.

**Прерывания.** Вкладка «Прерывания» показывает, какие касты врагов прерывали (прерываемой считается способность, которую в бою прервали хотя бы раз), сколько прошло и когда, кто прерывал и кто нажимал впустую. Ниже — очередь на следующий пулл: сначала те, кто прерывал эту способность, потом — у кого прерывание откатано; откат — по таблице или по факту, если игрок жал чаще. Если касты идут чаще, чем успевают даже пятеро, программа об этом скажет. Кнопка **«Скопировать для MRT (прерывания)»** — отдельная заметка: на каждую способность очередь по порядку и запасной.

**Лекари.** Вкладка «Лекари»: лечение и доля каждого лекаря, оверхил, мана к концу боя (и с какого момента её не было), «в пики» — во сколько раз лекарь лечит сильнее обычного в пики урона по рейду. Ниже — внешние сейвы на игроков (кому, когда, выжила ли цель) и смерти в пик урона, когда внешний сейв лекаря был откатан. Смерти от луж и в конце вайпа не считаются.

**Discord.** Под «Главным по бою» — кнопка **«Скопировать для Discord»**: короткая сводка боя (исход, главное, ссылка на лог) — вставить в канал гильдии. В режиме «Все боссы отчёта» — ещё и итоги вечера; если текст длиннее 2000 символов (предел сообщения Discord), он разбит на несколько сообщений.

**Живой лог.** Если отчёт пишется прямо сейчас (Warcraft Logs Uploader в режиме Live Log), нажмите «Найти бой», затем **«Следить за логом»**: раз в минуту программа смотрит, не появился ли новый пулл, и сама его разбирает — урон, сейвы, смерти, танки, лекари, прерывания (без ротации, чтобы хватило лимита WCL). Разбор попадает в историю, вкладка браузера и уведомление сообщают, что он готов. Если пуллов несколько сразу — разбирается последний. Слежение останавливается кнопкой или само, если лог не пополнялся полтора часа. Страницу держите открытой: на телефоне браузер в фоне может её усыпить.

**Итоги пуллов в Discord.** Во время слежения за живым логом итог каждого нового пулла может сам уходить в канал Discord:

1. В Discord: настройки канала → «Интеграции» → «Вебхуки» → «Новый вебхук» → «Копировать URL вебхука».
2. В программе вставьте ссылку в поле «Ссылка вебхука Discord» (хранится только на этом устройстве) и нажмите «Пробное сообщение» — проверить, что сообщение пришло.
3. Выберите, что отправлять: итог пулла и «Кому что поправить» или только итог. «Кому что поправить» — ошибки конкретных игроков, их увидят все в канале; для них удобен отдельный канал для офицеров.
4. **«Начать отправку в Discord»** — если слежение за логом ещё не запущено, оно запустится само. **«Остановить отправку в Discord»** — сообщения больше не уходят, слежение продолжается.

В сообщении: босс, сложность, исход и длительность (заголовок — ссылка на бой), главное по пуллу, «Кому что поправить» и номер пулла. Названия способностей — ссылки: на гайд Mythic Trap, если он есть, иначе на Wowhead. Упоминаний нет — даже если в тексте окажется @everyone, никого не позовёт. Очки Warcraft Logs на отправку не тратятся. Если Discord не ответил, разбор не ломается — под кнопкой будет написано, что сообщение не ушло.

## 5. Другие режимы

| Режим | Как запустить | Что получите |
| --- | --- | --- |
| Все боссы отчёта | В списке «Бой» — «Все боссы отчёта», затем «Разобрать бой» | вкладка на каждого босса с полным разбором и заметкой MRT (берётся последний килл, без киллов — лучший пулл), плюс «Ротация по боссам» |
| Топ прогресса | Кнопка «Топ прогресса» после «Найти бой» — или без лога: блок «Топ прогресса без лога» → версия игры, рейд, сложность, босс | бой первой гильдии, которая убила босса и выложила открытый лог убийства: кто что жал, смерти, заметка MRT. Закрытый лог — берётся следующая гильдия |
| План по составу | Блок «План сейвов по составу»: рейд, сложность, босс, минуты боя и состав → «Расписать сейвы» | план и заметка MRT для вашего состава по киллам топа похожей длительности — свой лог не нужен |

Состав для плана берётся из аддона [WoWUtils Group Export](https://www.curseforge.com/wow/addons/wowutilsgroupexport): в игре, в группе или рейде, наберите `/wugx`, нажмите Ctrl+C и вставьте в поле «Состав». Таланты аддон не передаёт, поэтому кулдауны-таланты берутся те, что жмут лучшие гильдии; если у лекаря другой талант — поправьте строку в заметке. Спеки игроков вне радиуса осмотра аддон угадывает и предупреждает об этом — подойдите к рейду и подождите, пока предупреждение исчезнет.

## 6. Лимит, файлы, история, обновления

- **Сравнение с эпохальным топом** (для героического и обычного боя) — галочка «Также сравнить с эпохальным топом». По умолчанию выключена: это вдвое больше загрузок и лимита.
- **Лимит Warcraft Logs.** У каждого ключа есть часовой лимит запросов. Кончился — готовые вкладки остаются, у остальных появится «Продолжить»: нажмите после сброса, уже скачанное повторно лимит не тратит. Галочка «ждать сброса лимита» продолжит сама — не закрывайте страницу.
- **Куда сохраняются файлы.** Раздел «Куда сохранять файлы»: по умолчанию «Загрузки», путь показан полностью; «Выбрать папку…» и «Открыть папку». Туда идут Excel и резервные копии.
- **Скачанные логи** хранятся не файлами, а в кэше программы (файл `wcl_cache.sqlite`). Он чистится сам: старше 3 недель удаляется, больше 500 МБ не растёт. Размер и кнопка «Очистить кэш» — в том же разделе.
- **История разборов** сохраняется на устройстве в сжатом виде (до 40 разборов и не больше 30 МБ, старые удаляются сами): открыть старый разбор и его Excel можно без интернета.
- **Мои данные → «Сохранить в файл»** — резервная копия ключа, эталонов, настроек и истории. Сделайте её перед очисткой браузера или переездом на другой компьютер.
- **Обновления** приходят сами: программа предложит обновиться и перезапустится. Ссылки на гайды по новым рейдам обновляются раз в неделю вместе с программой. Если новая версия не запустится, программа сама вернётся к прежней. Обновляйтесь, когда разбор закончен.

Вернуть данные из резервной копии — «Мои данные» → «Загрузить из файла». На компьютере откроется обычный выбор файла; на телефоне — список копий из «Загрузок», новые сверху. Android показывает приложению только файлы, которые оно сохранило само: копию с компьютера или сделанную до переустановки переносите ссылкой переноса (раздел 2).

## 7. Частые вопросы

| Вопрос | Ответ |
| --- | --- |
| «Нужен ключ» / ключ не принят | Проверьте, что вставлены и Client ID, и Client Secret без пробелов. Клиент на warcraftlogs.com можно создать заново. |
| Разбор остановился на лимите | Дождитесь сброса (до часа) и нажмите «Продолжить» — или сразу ставьте галочку «ждать сброса лимита». |
| Топ прогресса пишет «лог закрыт» | Не все гильдии открывают логи; программа сама берёт следующее место и пишет, чьи логи недоступны. |
| В заметке MRT не та фаза | Номера фаз берутся из лога и считают переходы по порядку; сверьте с босс-модом и при нужде поправьте `p2`/`p3` в заметке. |
| Где мой Excel? | В папке из «Куда сохранять файлы» (по умолчанию «Загрузки»), на телефоне — «Загрузки/WCL Analyzer». Полный путь показывается после сохранения. |
| Можно ли пользоваться с телефона через компьютер? | Да: «На другом устройстве» покажет QR-код для открытия программы в домашней Wi-Fi сети. |
| Программа не открывается на компьютере | Убедитесь, что чёрное окно не закрыто, и откройте адрес из него в браузере. Антивирус может блокировать неподписанную программу — добавьте её в исключения. |
| Пропал ключ API | «Мои данные» → «Загрузить из файла», ссылка переноса с другого устройства или вписать заново с warcraftlogs.com/api/clients. На компьютере ключ привязан к адресу страницы: открывайте её по тому же адресу, что в чёрном окне. |
| Нет описания способности | Нажмите кружок «i» после названия — описание скачается с Wowhead. Если нет связи, под ним есть ссылка на Wowhead или гайд Mythic Trap. |
