# Правила работы с этим репозиторием

- Любое изменение кода — по навыку **ub-mode** (по умолчанию, без отдельной команды):
  сначала заставить работать, потом сделать правильно, потом практика. Тест — до правки, и он должен упасть
  по ожидаемой причине; маленькие коммиты «зачем / что / как проверено»; в конце — лог действий.
- Отчёт пользователю — по-русски.
- Ключи Warcraft Logs — только в секретах GitHub (`WCL_CLIENT_ID`, `WCL_CLIENT_SECRET`), никогда в файлах репозитория.
  Хранилище ключей подписи APK не коммитить.
- Тесты: `WCL_GAME_DATA=bundled python tests/test_<набор>.py` для всех четырёх наборов.
- Проверка на настоящих логах — через ветку `debug/log` (workflow `check_log.yml`): из песочницы
  warcraftlogs.com, mythictrap.com и Wowhead недоступны.
